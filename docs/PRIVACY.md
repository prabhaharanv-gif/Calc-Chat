# Privacy Policy (draft - replace [CONTACT EMAIL] and host publicly)

Last updated: [DATE]

**What the app is.** A private two-person chat. The app is presented as a collection of mini games; a passcode set by you opens the chat.

**Accounts.** None. We do not ask for your name, phone number or email.

**What we process.** Messages, photos, voice notes and videos you send are relayed through our server so the other person receives them. They are held only in server memory (RAM), are never written to disk or a database, and are automatically deleted 4 hours after sending, when either person clears the chat, or when a wipe is triggered (3 wrong passcode attempts). Restarting the server also deletes them.

**What stays on your device.** Your hashed passcode, your chat code and a random secret that proves you own it. Messages are not saved on the device.

**Sharing.** We do not sell or share data, show ads, or use analytics or trackers. Content is visible only to the two people in a chat and, technically, to the server operator while it is in memory.

**Security.** Traffic uses HTTPS. Message text, photos, voice notes, videos and file names are end-to-end encrypted on the devices (AES-256-GCM with a key agreed between the two devices); the server relays ciphertext it cannot read. The server can see metadata such as which devices share a chat, message times and sizes, reactions and display names. The Android app blocks screenshots and screen recording.

**Permissions.** Microphone (voice messages), file access via the system picker (photos/videos you choose).

**Children.** Not intended for children under 13.

**Changes.** We will update this page and the date above if this policy changes.
