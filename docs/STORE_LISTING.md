# Play Store listing (draft)

**Title (30):** Gamaroon: Games + Private Chat
**Short description (80):** Six classic games with a hidden, end-to-end encrypted private chat.

**Full description**
Play six classic mini games: Snake, 2048, Memory, Tic Tac Toe, Mines and Slide puzzle. Hold a game title (1-3 seconds, you choose), enter your secret PIN, and a private chat opens.

NOTE: This app is a private messenger hidden inside a games app. The chat stays hidden until you enter your PIN.

- No sign-up, no phone number, no email
- Every user gets a personal code; share it with one friend to start a one-to-one chat
- End-to-end encrypted text, photos, voice messages and videos
- Messages and media auto-delete after 30 minutes and are never stored in a database
- Clear the chat for both people at any time; delete, reply, edit and react to messages
- A discreet colour signal on the game titles tells you when a message is waiting
- Silent Auto-Wipe (optional): 3 wrong PIN attempts erase your chats
- Sent, delivered and read ticks, a safety number to verify your friend, and an online/offline switch per chat
- Screenshots and screen recording are blocked by default (switchable in Settings)
- Notifications never show names or message text, only a generic game reminder
